Splat node
~~~~~~~~~~

The **Splat** node generates the shape of a splash (of paint, mud...), a disc with
irregular splatter around it. It can for example be used as the mask of a **Paint** node.

.. image:: images/node_workflow_shapes_splat.png
	:align: center

Inputs
++++++

The **Splat** node does not accept any input.

Outputs
+++++++

The **Splat** node outputs a greyscale image of the splash, white on black.

Parameters
++++++++++

The **Splat** node accepts the following parameters:

* the impact size is the radius of the disc at the center of the splash

* the explosiveness is how far the splatter spreads around the disc
