Atlas Splitter node
~~~~~~~~~~~~~~~~~~~

The **Atlas Splitter** node: extracts an image of an atlas, by index (from the top left corner, row by row).

Inputs
++++++

* **Atlas**: The atlas (a grid of images)

Outputs
+++++++

* **Output**: The extracted image

Parameters
++++++++++

* **Columns**: The number of columns of the atlas
* **Rows**: The number of rows of the atlas
* **Index**: The index of the extracted image
