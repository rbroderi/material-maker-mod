Normal Normalize node
~~~~~~~~~~~~~~~~~~~~~

The **Normal Normalize** node makes all vectors of a normal map unit length. It is useful after
operations that do not keep normals unit length, such as mixing, blurring, warping or resizing a
normal map, or when importing normal maps that were stored with a low precision.

Inputs
++++++

* **Input**: the normal map

Outputs
+++++++

* **Output**: the normalized normal map, in the same format as the input

Parameters
++++++++++

* **Format**: the format of the input and of the output. *Default* is Material Maker's format,
  generated by the **Normal Map** node and expected by the **Material** node. *OpenGL* and *DirectX*
  are for normal maps in those formats (for example images, or the output of the **Normal Convert**
  node).

Notes
+++++

Null vectors become flat normals, and normals that point into the surface are moved onto it.
