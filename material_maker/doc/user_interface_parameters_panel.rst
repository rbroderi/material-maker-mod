Parameters panel
^^^^^^^^^^^^^^^^

The parameters panel shows all parameters of the current brush,
and can be used to modify them.

.. image:: images/parameters_panel.png
  :align: center

Parameters whose label is written **Group::Label** (for example the labels of a brush's
remote node) are shown under a collapsible *Group* header. Click the header to show or
hide the group's parameters.

Sliders cover the parameter's range, but values outside of it can be typed unless the
parameter also has a hard range (**hard_min** and **hard_max**, see
:ref:`shader-nodes-parameters`).
