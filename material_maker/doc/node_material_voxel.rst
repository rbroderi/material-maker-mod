Voxel Material node
~~~~~~~~~~~~~~~~~~~

The **Voxel Material** node is a material type for voxel objects and other objects textured
by their position in 3D. It is provided by the *Voxel materials* plugin.

Its inputs are 3D textures that are evaluated at the object-space position of the shaded
point, in metres. In the 3D preview, the object-space normal is available to the 3D texture
nodes (see the :doc:`Voxel Inputs <node_3d_voxel_inputs>` node), and the bump input perturbs
the normal.

Inputs
......

The **Voxel Material** node accepts the following inputs:

* **Albedo**, a 3D texture
* **Metallic**, **Roughness**, **Ambient occlusion** and **Opacity**, grayscale 3D textures
* **Emission**, a 3D texture
* **Bump**, a 3D texture that holds the gradient vector of a height (generated by a
  gradient node)

Parameters
..........

The **Voxel Material** node accepts the following parameters:

* the **Albedo** color and the **Metallic**, **Roughness**, **Emission** and
  **Ambient occlusion** strengths
* **Bump**: the strength of the bump. The normal becomes
  ``normalize(n - k*(g - n*dot(g, n)))``, where ``n`` is the geometric normal, ``g`` the gradient
  and ``k`` the bump strength
* **Linear albedo**: when unchecked, the albedo input is sRGB and is decoded to linear by the
  material; check it when the input is already linear
* **Preview scale**: the number of metres per unit of the 3D preview object

Limitations
...........

See the :doc:`Voxel Inputs <node_3d_voxel_inputs>` node: the normal is only available in the
preview, and in exports that use the normal, through the controlled variation, so the
**Controlled Variations** node cannot be used in a voxel graph, and buffers lose the normal
and the fresh value.
